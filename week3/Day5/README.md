# Week 3 Day 5 Capstone — Full AFL Assistant

## What is included
- `afl_langgraph_app.py`: hardened LangGraph app with deterministic scope routing, real structured retrieval, prediction tools, memory, rate limiting, timeout-safe error fallback, and Gemini phrasing.
- `api.py`: FastAPI `/chat` and `/health` endpoints.
- `streamlit_app.py`: minimal demo UI.
- `evaluation_results.csv` / `evaluation_summary.csv`: 29-case combined evaluation, generated by `test_evaluation_suite.py` (re-runnable, not a static claim).
- `benchmark.json`: real match-winner benchmark comparison against a ladder-position naive baseline on the 2025 holdout (model 66.5% vs ladder-naive 65.6% vs home-always 55.8%).
- `monitoring_checklist.md`: monitoring and weekly refresh plan.
- `executive_report.pdf`: concise two-page stakeholder report.
- `demo_script.md`: 5–7 minute presentation outline.
- `data/`: real AFL CSVs supplied for this project.

## Run
```bash
pip install -r requirements.txt
```
Set the Gemini key (do not commit it):
```bash
# Windows PowerShell
$env:GEMINI_API_KEY="YOUR_KEY"
# macOS/Linux
export GEMINI_API_KEY="YOUR_KEY"
```
Run the CLI demo:
```bash
python afl_langgraph_app.py
```
Run API:
```bash
uvicorn api:app --reload
```
Open `http://127.0.0.1:8000/docs`.
Run UI:
```bash
streamlit run streamlit_app.py
```

## Grounding and hardening
All numeric facts originate in tool results. Prediction responses preserve the disclaimer **"predicted probability, not a certainty"**. Scope checks run before retrieval/prediction. Repeated requests are rate-limited per conversation ID. Tool/model errors return a safe fallback instead of invented numbers. Structured request logs are written to `afl_monitor.log` by the API.

## Evaluation
The combined suite contains **29 cases** across factual Q&A, prediction sanity, scope guardrails, and multi-turn coherence — run `python test_evaluation_suite.py` to regenerate `evaluation_results.csv`/`evaluation_summary.csv` from scratch. Currently 29/29 pass after fixing 6 real bugs found during testing (team-name parsing, player surname resolution, an unwired top-player prediction tool, season-stat query routing, and two response-formatting gaps) — see `evaluation_results.csv` for the full case-by-case notes.
